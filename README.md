# Pulse Fitness

Pulse Fitness is a responsive, user-friendly gym website designed to inform potential and existing members about the gym, its classes, facilities, and contact details.

The site is built using HTML and CSS, following mobile-first and accessibility best practices.

---

## User Experience (UX)

### Site Goals
- Provide clear information about the gym and its services
- Encourage users to explore classes and facilities
- Make it easy to find contact and opening hours information

### Target Audience
- Local residents looking for a gym
- Existing members seeking class schedules and updates
- Individuals of all fitness levels

---

## Features

- Responsive navigation menu
- Hero section with call-to-action
- Information sections for gym details, classes, and facilities
- Contact information and opening hours
- Accessible external social media links

---

## Technologies Used

- HTML5
- CSS3
- Git & GitHub

---

## Testing

The website was tested to ensure functionality, responsiveness, and accessibility.

### Manual Testing
- All navigation links scroll correctly to their respective sections
- External links open in a new tab
- Layout adapts correctly to mobile, tablet, and desktop screen sizes
- Content remains readable and well-structured across screen sizes

### Accessibility Testing
- Semantic HTML elements are used throughout
- ARIA labels are applied to navigation and external links
- Text contrast is sufficient for readability

### Browser Compatibility
The site was tested and works correctly on:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox

---

## Deployment

This site was deployed using GitHub Pages.

### Deployment Steps
1. Log in to GitHub
2. Navigate to the project repository
3. Go to **Settings**
4. Select **Pages**
5. Choose the **main** branch as the source
6. Save the settings
7. The live site link is generated by GitHub Pages
